# NEXUM local ticket tracker

`docs/wayfinder` is the single source of truth for NEXUM planning, decisions, specifications, and implementation work.

- Root-level `*-map.md` files, [DECISIONS.md](DECISIONS.md), and `*-spec.md` files are planning and discussion artifacts.
- [IMPLEMENTATION-TRACKER.md](IMPLEMENTATION-TRACKER.md) is the canonical operational overview.
- `tickets/*.md` is one flat directory containing implementation tickets. Completed tickets are kept here as the implementation record; their status is authoritative in each ticket and in [IMPLEMENTATION-TRACKER.md](IMPLEMENTATION-TRACKER.md).

`.scratch` is reserved for disposable generated output and browser logs. It contains no active tickets.
