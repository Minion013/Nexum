# 03 — Deliver criteria-gated milestone review decisions

**What to build:** A Buyer can evaluate the active milestone's required Acceptance Criteria, request a revision or raise a dispute independently, and accept the milestone only after a complete documented review.

**Blocked by:** 02 — Deliver private milestone evidence and activity.

**Status:** ready-for-agent

- [ ] The Milestone Review exposes a Criteria view whose required checks are based on the accepted Contract Version's milestone terms.
- [ ] Acceptance and any supported release action stay disabled until the Buyer completes every required Acceptance Criterion.
- [ ] A Buyer can request revision with a recorded reason or raise a dispute without completing the acceptance checklist.
- [ ] Criteria checks and every decision append to the protected milestone activity trail; only the authorised Buyer can make review decisions.
