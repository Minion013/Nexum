# Dark-mode scope and token policy

## Question

Should the hackathon MVP provide dark mode, and if so which semantic tokens, contrast rules, persistence behaviour, and visual surfaces are required before it can be offered as a supported setting?

## Resolution

Do not offer a supported dark mode in the hackathon MVP. Keep the semantic-token architecture capable of supporting a future theme, but design, implement, and test only the established light Contract-focused experience.
