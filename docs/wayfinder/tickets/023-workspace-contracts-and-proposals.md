# Workspace contracts and proposals

## Question

How should a Workspace own a table-first Contracts view and a role-led creation flow, while describing an unshared Contract Draft as a discreet Proposal rather than exposing “private draft” language?

## Resolution

Provide a Workspace-owned, table-first Contracts view with a role-led creation flow. Call an unshared Contract Draft a Proposal in the UI, without using “private draft” wording. A pre-draft Proposal is creator-only by default; another person gains access only through an explicit sharing or invitation action.
