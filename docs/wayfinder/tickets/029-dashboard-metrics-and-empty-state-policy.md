# Dashboard metrics and empty-state policy

## Question

Once durable Contract data is available, which Dashboard metrics, attention states, timeline states, and empty states give a Workspace useful next actions without implying unavailable payment or delivery authority?

## Resolution

Show a small set of action-oriented metrics: active Contracts, milestones needing attention, upcoming deadlines, and funded or released amounts only when chain-backed. Empty states lead with the next creation or invitation action; attention states link directly to the relevant Contract or Proposal.
