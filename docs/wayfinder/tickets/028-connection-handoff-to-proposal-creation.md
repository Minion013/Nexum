# Connection handoff to Proposal creation

## Question

How should an accepted professional connection be presented during Proposal creation so it can simplify counterparty selection without granting Workspace membership, Contract access, or an implicit invitation?

## Resolution

Provide an optional From your network selector in Proposal creation. It lists only accepted connections and merely pre-fills the named counterparty or Contact. The creator must still explicitly choose the counterparty and send the Proposal invitation. Manual Contact entry remains available. Selecting a connection grants no Workspace membership, Contract visibility, or invitation acceptance; those arise only through the normal explicit invitation flow.
