# 04 — Deliver role-led Contract Draft creation

**Parent:** [PactFlow post-login retired model redesign specification](../post-login-retired model-redesign-spec.md)

**What to build:** A user creates a Contract Draft in an owning retired model by choosing “I’m hiring a service provider” or “I’m providing a service,” then naming an exact-email counterparty. The resulting Contract records complementary Buyer and Service Provider responsibilities, stays accessible only to authorised initiating Contract Parties until explicitly shared, and uses quiet privacy guidance.

**Blocked by:** 03 — Deliver table-first retired model Contracts.

**Status:** ready-for-agent

- [ ] Contract Draft creation requires an owning retired model and explicit initiating Buyer or Service Provider responsibility.
- [ ] The new Contract records the inverse responsibility for the counterparty without changing either person’s Profile or retired model authorization.
- [ ] The UI uses Contract Draft language, provides a single understated privacy explanation, and removes “private draft” and “private Contract” headline/action copy.
- [ ] Authenticated creation tests prove retired model ownership, responsibility assignment, exact-email invitation behavior, and unchanged unauthorized-access rejection.
